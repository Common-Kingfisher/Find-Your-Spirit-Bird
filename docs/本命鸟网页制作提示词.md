> 当前主数据文件：`outputs/15-bird-rebuild-v1/本命鸟测试配置-15种-网站版.xlsx`  
> 网站数据文件：`site/app/data/quiz-data.json`  
> 如手册与工作簿内容冲突，以工作簿为准。

## 1. 产品口径

- 产品名称：测测你的本命鸟
- 产品类型：轻量人格测试＋中国野生鸟类图鉴
- 正式名录：15 种中国原生野生鸟类
- 分层：普通款 N 9 种、稀有款 R 4 种、隐藏款 UR 2 种
- 题目：12 条陈述句，每题使用 7 档“同意—不同意”量表
- 维度：社交能量、行动节奏、表达强度、探索倾向、秩序偏好、处事锋芒
- 结果：从 15 种鸟中确定性匹配第一名，并展示第二、第三名
- 隐私：答案只在浏览器本地计算，不上传、不注册、不登录
- 声明：本测试仅供娱乐，不构成心理学、医疗、职业或其他专业判断

N / R / UR 只控制主页分组、结果徽章与揭晓动画，不参与计分，也不代表现实常见度、野外可见概率或保护等级。不得设置结果占比、抽取概率或档位配额。

## 3. 页面结构

### 主页

主页必须直接展示全部 15 种“鸟格”，按 N / R / UR 分组。每种至少显示：

- 中文名、英文名、学名
- 昵称与一句话鸟格
- 三个性格关键词
- 一句典型习性或生境
- 分层徽章

主页不显示出现率、概率或“抽中难度”。角色图未完成时使用统一的栖息地占位视觉，不能显示裂图。

### 答题页

- 参考 16Personalities 的清晰答题节奏，但不复制其品牌、人物、文案、颜色或具体版式
- 每次显示一条陈述
- 从左到右为“同意 → 不同意”
- 7 个圆点依次对应 `+3、+2、+1、0、-1、-2、-3`
- 圆点大小从两端向中间递减
- 同意端用松针绿，不同意端用羽冠紫，中立为灰色
- 必须支持键盘焦点、上一题、修改答案和减少动态效果
- 答题过程中不得显示分数变化或暗示对应鸟类

### 结果页

1. 揭晓主视觉：AI 鸟格角色图、鸟名、昵称、英文名、等级、匹配度
2. 鸟格速写：为什么是它＋三个关键词
3. 鸟格坐标：用户值与本命鸟目标值的六维对照
4. 深入分析：优势、隐藏侧面、容易被误解
5. 关系鸟谱：第二、第三匹配、最合拍鸟、反差鸟
6. 今日飞行建议：根据六维分数生成 2～3 条温和建议
7. 科普区：用户自有照片、外貌、生境、习性、范围/保护提醒、资料来源
8. 分享、重新测试与娱乐声明

科普事实与人格映射必须视觉分区，不能把真实鸟类习性包装成心理学因果。

## 4. 计分方法

每题记录一个回答值：

`强烈同意 +3｜比较同意 +2｜稍微同意 +1｜中立 0｜稍微不同意 -1｜比较不同意 -2｜强烈不同意 -3`

每条题目拥有六维向量，单个向量值范围为 `-2～2`。回答值与题目向量相乘，得到该题对六个维度的贡献。

每个维度独立归一化：

`最大绝对分 = 3 × Σ abs(该维度所有题目向量)`

`维度得分 = 50 + 50 × 该维度贡献总和 ÷ 最大绝对分`

最终得分限制在 `0～100` 并四舍五入。逐维归一化可以避免某个维度因为相关题目更多而天然更容易得到极端值。

鸟类匹配：

`距离 = sqrt(六个维度差值平方之和 ÷ 6)`

`匹配度 = 100 - 距离`

按匹配度降序排列；完全同分时按鸟类资料中的“结果优先级”排序。不得加入随机数。

- 用途：主页鸟格卡和结果揭晓主视觉
- 目录：`site/public/birds/characters/`
- 文件名：`鸟类ID.png`，例如 `N01.png`
- 当前已完成样片：麻雀、长耳鸮、中华凤头燕鸥
- 绿孔雀样片为废案，不进入正式网站
- 风格：原创低多边形 / 几何切面角色图
- 必须保留物种关键识别特征与典型生境切片
- 不生成文字、徽标、水印、MBTI 字母或 16Personalities 角色

现有两张样片暂时保留原文件名，网站数据层负责映射；批量生成时统一改为鸟类 ID 命名。

## 6. 揭晓动画

- N：经典烟花＋花瓣；提示“你的本命鸟已落在枝头”
- R：鸟群横穿后显露稀有徽章；提示“发现稀有鸟格”
- UR：两层远近鸟群＋短暂停顿；提示“隐藏鸟格出现”
- 开启减少动态效果时，取消粒子与横穿位移，仅保留 200～400ms 淡入和完整文字
- 不使用赌场式金光、抽卡音效或把濒危处境娱乐化的表达

## 7. 技术路线

网站采用纯前端、无账号、无数据库、无模型接口的结构：

- 题目、权重、鸟类资料编译进本地 JSON
- 浏览器本地完成计分
- 所有正式图片随站点打包
- 不依赖 Google Fonts、境外图片 CDN、第三方统计脚本或运行时 API
- 不把数据写死在组件中
- 不使用任何托管平台专有数据库或服务端函数

这使同一份源码可以部署到 Sites、EdgeOne Pages、Cloudflare Pages 或其他静态/边缘托管平台，不需要重写测评逻辑。

### 发布顺序

1. Sites：用于当前内部测试和视觉验收
2. EdgeOne Pages：公开小流量测试的优先候选，可直接构建 React / Next 项目
3. Cloudflare Pages：零成本备选
4. 若要求中国大陆长期稳定并使用大陆节点：准备自有域名、实名认证和 ICP 备案

零成本境外边缘托管通常可以被中国大陆访问，但无法承诺所有地区、运营商和时段都稳定。使用中国大陆服务器或大陆 CDN 节点时通常需要备案；因此项目从第一天保持无后端、可迁移，避免以后因换托管平台大改。

## 8. 本地调试

开发版可以提供隐藏校准面板，至少包含：

- 当前 12 题回答值
- 六个维度得分
- 15 种鸟的完整匹配排名
- 每种鸟与用户的六维差值
- 匿名结果 JSON 导出
- 随机答案模拟与不可达结果提示

正式公开版默认隐藏调试面板。测试和正式页面必须调用同一套计分函数。
